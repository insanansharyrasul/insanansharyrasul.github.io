# Blog Media Assets

Taruh berkas screenshot, GIF demo, dan video untuk artikel blog di dalam direktori ini.
Contoh:
- `ipb-auto-logbook-overview.png`
- `csv-format-preview.png`
- `chrome-load-unpacked.png`
- `chrome-extension-demo.gif`
- `desktop-gui-preview.png`
- `tutorial-walkthrough.mp4`

Berkas di dalam direktori `static/blog/` dapat diakses langsung pada browser lewat URL path `/blog/<nama-berkas>`.
